The Platform

Four pillars that act as one loop

Not a dashboard. A cycle: predict, advise, intervene, follow up.

🪪
Smart ID
Digital student card with a QR code, plus ID-card photo login (OCR). No password needed.
🎓
Academic Record
GPA, failed courses, semester trend, study plan and credits remaining to graduation.
📅
Smart Attendance
Per-session attendance, per-course rate, and an automatic alert below 75%.
🧠
AI Early Warning
A machine-learning model that classifies risk and explains what drives it.

How it works

From record to intervention in five steps

Fully automated and explainable at every step.

  1. DataGrades, attendance, engagement, warnings
  2. ModelRandom Forest on 26 features
  3. Risk score0 to 100, with reasons
  4. AdvisorRanked queue and recommendations
  5. StudentNotification, message, action plan

Security and Privacy

Student data is a trust

Six controls implemented in the code, not promises on a slide.

🔑
JWT authentication
Every request is protected by a signed token with automatic expiry.
🛡️
API-level RBAC
Student, advisor and admin roles are verified on the server, never in the browser.
🧱
Student data isolation
A student cannot reach another student's record, whatever the URL says.
🔒
Secret hygiene
bcrypt passwords. API keys are never logged and never returned.
📜
Audit log
Every sensitive action is recorded with actor, IP and time (129 so far).
🚧
Upload and abuse guard
File type, size and access checks, plus rate limiting per user.

Roadmap

Four phases, each independent and low-risk

Start small, prove impact, then scale.

PHASE 1
One faculty, one semester

  • Measure meetings and closed cases
  • Measure GPA movement at term end
PHASE 2
Integration

PHASE 3
Mobile
  • React Native application
  • Push notifications
  • Advisor appointment booking
PHASE 4
Predictive analytics
  • Course planning and forecasting
  • Retrain the model on real cohorts
  • Roll out to every department
